SENS Installer

Instalação experimental do firmware SENS diretamente pelo navegador.

Placa: ESP32 DevKit V1
Firmware: SENS V2.2.1 RC5B8 REV04B BATCH_50
Este navegador não oferece o recurso necessário para instalação via USB.

PoC 1 — esta versão testa somente a instalação web. A configuração do equipamento ainda é a configuração compilada no firmware.
