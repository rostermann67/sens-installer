ETAPA 2 — INSTALAÇÃO

Instale o SENS

O Wi‑Fi automático do ESP Web Tools está desativado nesta versão. Terminada a instalação, use a Etapa 3: ela grava automaticamente o Nome + Serial já salvos e, na mesma conexão USB, segue para a rede.

ETAPA 3 — GRAVAR CONFIGURAÇÃO SENS

Envie a configuração salva ao ESP32

Depois de instalar, clique uma vez abaixo e selecione a porta do ESP32. O Installer grava Nome + Serial juntos, em uma única operação atômica na NVS. O próprio firmware devolve os dois valores confirmados; só há uma leitura de recuperação se o retorno se perder.

Aguardando instalação e conexão com o ESP32.
