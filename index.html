SENS INSTALLER

Instalação e atualização do firmware SENS para ESP32 DevKit V1

Firmware: 2.2.1-RC5B8 Rev.06E MULTI-BATCH RESUMO

ATUALIZAR SENS — PRESERVAR DADOS

Use em um equipamento SENS já configurado. Esta opção foi preparada para manter NVS e LittleFS, preservando Epoch, Seq e buffer.

IMPORTANTE: se aparecer a opção Erase device, deixe a caixa DESMARCADA.
Use Chrome, Edge ou outro navegador compatível com Web Serial em HTTPS. A instalação exige uma página HTTPS. Após atualizar, confirme no Serial que o Epoch permaneceu igual e o Seq continuou.

INSTALAR SENS DO ZERO

Use somente para equipamento novo ou quando quiser apagar a identidade e os dados persistentes anteriores.

ATENÇÃO: esta opção apaga os dados persistentes do ESP32. O próximo boot deverá criar novo Epoch e reiniciar a sequência.
Use Chrome, Edge ou outro navegador compatível com Web Serial em HTTPS. A instalação exige uma página HTTPS. Não use esta opção para uma atualização normal.
