SENS INSTALLER V2.10.2 — REV.15A CONFIGURAÇÃO ATÔMICA NVS

Firmware: 2.2.1-RC5B8 Rev.15A CONFIG ATÔMICA NVS

FLUXO
1. Pré-configuração neutra na página (sem importar dados da V2.10/V2.10.1).
2. Instalação DO ZERO ou PRESERVAR.
3. Identidade atômica Nome + Serial.
4. Configuração completa é preparada em RAM: Básico + Avançado + Genéricos 1/2 + Correções 1/2.
5. Um único COMMIT persiste a configuração.
6. O firmware recarrega a própria NVS e devolve um snapshot lógico para confirmação.
7. Wi-Fi.
8. Monitor serial.

OBSERVAÇÕES
- A V2.9.2 / Rev.14 permanece como pacote separado de segurança e não é alterada por este ZIP.
- O formulário usa uma nova chave local de versão (sensInstallerV2102), evitando herdar Estação Vazão / SENS-200 ou outros dados salvos pela V2.10/V2.10.1.
- Os manifests desta versão têm nomes próprios v2102 para evitar cache/referência a manifests anteriores.
