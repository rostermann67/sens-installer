SENS INSTALLER V2.1 — IMPROV WIFI — PoC
Firmware: 2.2.1-RC5B8 Rev.07 IMPROV WIFI

OBJETIVO
Provar provisionamento de Wi-Fi pelo navegador após instalação via ESP Web Tools.

TESTE RECOMENDADO
1. Publicar TODO o conteúdo desta pasta no GitHub Pages.
2. Abrir a página em Chrome/Edge via HTTPS.
3. Clicar INSTALAR DO ZERO.
4. Selecionar a porta do ESP32.
5. Concluir a gravação e MANTER o cabo conectado.
6. O ESP Web Tools deve aguardar/detectar Improv Serial.
7. Informar SSID e senha pelo navegador.
8. Confirmar no log que o ESP conectou.
9. Confirmar na SENS Platform novo Epoch e Seq iniciado em 1.
10. Reiniciar o ESP e confirmar que o Wi-Fi reconecta sem Arduino IDE.

NOTA
Esta é uma PoC. A Rev.06E e o SENS Installer V1 permanecem congelados.
