SENS INSTALLER V2.3 — WIZARD
Firmware: Rev.09 WIZARD SERIAL

Publicação:
1. Envie TODO o conteúdo desta pasta para a raiz do repositório GitHub Pages.
2. Aguarde a atualização do Pages e abra o endereço HTTPS.
3. Etapa 1: informe Nome + Serial e clique Guardar configuração.
4. Etapa 2: escolha DO ZERO ou PRESERVAR.
5. Etapa 3: após a instalação, configure Wi-Fi pelo Improv.
6. Etapa 4: clique FINALIZAR CONFIGURAÇÃO SENS e selecione a porta ESP32 novamente.

Teste inicial recomendado:
- manter Serial SENS-003;
- alterar somente o Nome;
- verificar na Platform se o mesmo Serial aparece com o novo nome;
- pressionar RESET e confirmar persistência.

ATENÇÃO:
Esta é uma PoC V2.3. A troca de Serial ainda não força novo Epoch automaticamente.
No caminho PRESERVAR, não marque a opção de apagar o dispositivo.
